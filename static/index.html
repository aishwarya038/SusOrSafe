Our Services

Six tools that cover the first minutes of a malware investigation

Live hash reputation

The SHA-256 is computed in your browser, then checked on VirusTotal and MalwareBazaar.

In-memory static analysis

Entropy, file type and suspicious API, macro and script strings are read from memory. Nothing is run or saved.

Explainable score

A 0 to 100 risk score where every point is listed with its reason.

AI analysis

An AI writes the summary and next steps. It explains the verdict and never decides it.

Package check

Find malicious or vulnerable dependencies in requirements.txt or package.json.

Log check

Upload a server or auth log to detect SQL injection, XSS, brute force and scanner tools. Live IP check included.
